## 🛡️ BATTLE NOTES (CONCEITOS TÁTICOS DO EXAME)

Resumo técnico dos conceitos validados no Checkpoint Exam:

### 📊 SOC Metrics (Métricas de Defesa)
Diferenciação crítica para análise de performance do time:
* **MTTD (Mean Time to Detect):** Tempo médio para o time *identificar* que um ataque está acontecendo.
* **MTTC (Mean Time to Contain):** Tempo médio para *conter* o incidente, impedindo que se espalhe e cause mais danos.
* **MTTR (Mean Time to Respond):** Tempo médio para *conter e remediar* o incidente completamente.
* **Dwell Time:** O tempo que o inimigo permaneceu escondido na rede antes de ser detectado.

### 🧠 Inteligência & Ferramentas
* **SIEM "Secret Sauce":** A principal função não é apenas guardar logs, mas **combinar dados de múltiplas tecnologias** (Firewall + EDR + IDPS) para achar correlações.
* [cite_start]**Tripé do SOC:** Pessoas, Processos e Tecnologias[cite: 281].

### 🗃️ Classificação de Dados (Data Privacy)
* **PII (Personal Identifiable Information):** Dados que identificam o civil (ex: Nome, CPF, Cartão de Crédito).
* **PHI (Protected Health Information):** Dados sensíveis de saúde/hospitalares (ex: Prontuários).

### 👾 Bestiário de Ameaças (Threats)
* **Rogue Access Point:** Dispositivo não autorizado na rede (Evil Twin).
* **DDoS:** Ataque coordenado usando uma *botnet* de zumbis.
* [cite_start]**IoT Risk:** O maior perigo é a falta de atualizações de firmware e softwares embarcados antigos[cite: 205, 206].
