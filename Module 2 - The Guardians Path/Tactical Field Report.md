## 💼 Lab 2.2.5: Becoming a Defender

**Objetivo:** Análise de mercado e ferramentas de treinamento para analistas SOC.

### 1. Radar de Certificações
Pesquisa sobre as credenciais mais exigidas pelo mercado de cibersegurança:

* **Cisco Certified CyberOps Associate** (Foco: Operações de SOC)
* **CompTIA Security+** (Foco: Fundamentos Gerais)
* **CEH (Certified Ethical Hacker)** (Foco: Pentest / Red Team mindset)

### 2. Análise de Vagas (Glassdoor/LinkedIn)
Requisitos comuns identificados para posições "Junior Analyst":
* ✅ Monitoramento de Logs (SIEM).
* ✅ Resposta a Incidentes.
* ✅ Conhecimento em Linux e Redes (TCP/IP).

### 3. Training Grounds: Google Gruyere
Exploração da plataforma **Google Gruyere** para prática de "Web Application Exploits and Defenses".
* **Conceito:** Aplicação web intencionalmente vulnerável.
* **Missão:** Executar ataques (XSS, SQLi) de forma ética para entender como bloqueá-los.
